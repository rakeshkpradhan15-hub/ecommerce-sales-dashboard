# Ecommerce Sales Dashboard - Power BI

## Project Overview
This project is an interactive Ecommerce Sales Dashboard built using Power BI to analyze sales performance, profitability, customer trends, and regional insights.

---

## Objectives
- Analyze sales trends and profit performance
- Identify top-performing categories and regions
- Track important KPIs
- Build interactive business reports

---

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization

---

## Dashboard Features
- KPI Cards
- Monthly Profit Analysis
- State-wise Sales Analysis
- Category-wise Performance
- Interactive Filters & Slicers

---

## Key Insights
- Certain months generated higher profits
- Regional analysis identified top-performing states
- Product categories contributed differently to revenue and profit
